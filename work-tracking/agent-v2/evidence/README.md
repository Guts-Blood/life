# Evidence

Put raw evidence here when it does not already live in a repo, PR, eval dashboard, or run log.

Good examples:

- Screenshots or copied snippets from eval results.
- Short notes from manual case review.
- Links to PRs, commits, dashboards, docs, or experiment outputs.
- Before/after summaries that should not be lost in chat.

Prefer linking to the source of truth when there is one. Use local files here for lightweight
snapshots and synthesis.
