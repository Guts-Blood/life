# Work Tracking

This folder tracks work that needs a tighter operating rhythm than the broader
life-system loop.

## Current Systems

- [agent_v2 launch tracking](agent-v2/dashboard.md)
- [AI trends and paper catch-up](research/ai-catchup.md)

## Status Legend

- `scoping`: shape is known, details still being collected
- `doing`: implementation or iteration is in progress
- `validating`: change is ready and needs eval, rollout, or review evidence
- `blocked`: waiting on a dependency or decision
- `ready`: ready to merge, launch, or hand off
- `shipped`: merged or launched, with follow-up evidence recorded
- `parked`: intentionally paused

## Update Rhythm

- Daily: update the dashboard rows that moved.
- Per meaningful change: add one row to the related workstream ledger.
- Per eval or intern run: add one row under `runs/`.
- Weekly: summarize decisions, evidence, and next focus in `logs/`.
