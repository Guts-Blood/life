# Repo Schema

## `profile/`

Stores personal context. Split stable identity from seasonal context so conclusions can be
interpreted against the right background.

## `assumptions/`

Stores claims that are meaningful enough to test. The folder state represents lifecycle:

- `inbox/`: captured but not shaped
- `active/`: under test
- `verified/`: supported for now
- `falsified/`: did not hold
- `archived/`: no longer relevant

## `experiments/`

Stores verification plans. An experiment should make clear what is being tested, over what
window, and with what signals.

## `evidence/`

Stores raw observations, notes, references, and snapshots. Keep this more factual than
interpretive.

## `principles/`

Stores durable conclusions that should influence future decisions. A principle should usually
be supported by multiple observations or a strong repeated pattern.

## `reviews/`

Stores periodic maintenance of the whole system.
